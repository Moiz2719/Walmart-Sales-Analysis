# Local dataset

Download the Customer Personality Analysis dataset from the [Kaggle dataset page](https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis).

Create the folder data/raw and place the source file here:

- data/raw/marketing_campaign.csv

The source file is not committed to this repository. Check the dataset licence and terms before redistribution. Keep any customer-level or sensitive data local; do not commit raw records to a public GitHub repository.
