# Data dictionary

The project is designed for the Kaggle Customer Personality Analysis dataset. Field availability should be checked in the source file before running the pipeline.

## Customer and household fields

| Field | Description |
|---|---|
| ID | Customer identifier; retained for traceability but not used as a clustering feature |
| Year_Birth | Customer birth year |
| Education | Education category |
| Marital_Status | Marital-status category |
| Income | Yearly household income in the dataset's source units |
| Kidhome | Number of young children in the household |
| Teenhome | Number of teenagers in the household |
| Dt_Customer | Date the customer enrolled with the company |
| Recency | Days since the customer's last purchase |
| Complain | Complaint indicator in the source dataset |

## Spending and channel behaviour

| Field | Description |
|---|---|
| MntWines, MntFruits, MntMeatProducts | Spending by product category |
| MntFishProducts, MntSweetProducts, MntGoldProds | Spending by product category |
| NumDealsPurchases | Purchases made using discounts |
| NumWebPurchases | Purchases through the website |
| NumCatalogPurchases | Purchases through the catalogue |
| NumStorePurchases | In-store purchases |
| NumWebVisitsMonth | Website visits in the preceding month |

## Campaign fields

| Field | Description |
|---|---|
| AcceptedCmp1–AcceptedCmp5 | Acceptance indicator for earlier campaigns |
| Response | Response indicator for the most recent campaign |

## Engineered fields

| Field | Description |
|---|---|
| Age | 2014 minus Year_Birth; reference year fixed for reproducibility |
| Children_Total | Kidhome plus Teenhome |
| Family_Size | Children_Total plus one adult/partner proxy; a simplified feature |
| Is_Parent | One when Children_Total is greater than zero |
| Living_With | Simplified grouping of marital-status labels |
| Total_Spending | Sum of the six Mnt* product-spending fields |
| Total_Purchases | Sum of purchase counts across deal, web, catalogue, and store channels |
| Campaigns_Accepted | Sum of AcceptedCmp1–AcceptedCmp5 indicators |
| Customer_Tenure_Days | Days from enrolment to the latest Dt_Customer date present in the dataset |
| Segment_ID | K-Means cluster assignment generated by the pipeline |
