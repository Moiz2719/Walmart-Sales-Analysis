# Project overview

## Business context

Generic marketing messages may not work equally well for all customers. A business can use purchasing patterns and engagement data to identify groups with similar behaviours, then tailor offers and retention activity to each group's needs.

## Objectives

- Clean the customer marketing dataset and inspect data quality.
- Create interpretable features for customer age, household composition, spending, purchases, campaign acceptance, and customer tenure.
- Scale behavioural features and use K-Means clustering to form customer segments.
- Compare candidate cluster counts using a silhouette score.
- Profile each segment with spending, channel, recency, and campaign-response measures.
- Build visuals and derive testable business recommendations.

## Deliverables

- Reproducible Python scripts.
- Segment assignment dataset generated locally.
- Cluster evaluation metrics and segment profile tables.
- Visualisations that can be included in a portfolio or presentation.
- Documentation of methodology and interpretation.

## Scope

This is a descriptive segmentation exercise using the fields available in the selected marketing dataset. Results should be interpreted as patterns in the observed sample, not as proof of future customer behaviour.
