# Project overview

## Purpose

This project explores a retail transaction dataset to identify patterns in payment method usage, product-category ratings, branch activity, time-of-day transaction volume, and a dataset-derived estimated profit measure.

## Business context

Retail teams can use transaction and customer-rating data to understand how customers pay, which categories receive stronger ratings, and when transaction activity is concentrated. Branch-level comparisons can help identify questions for further operational investigation.

## Scope

- Inspect and clean the CSV data with pandas.
- Load the cleaned data into SQLite.
- Use SQL aggregations and window functions to answer business questions.
- Generate visualisations with Matplotlib.
- Document assumptions and limitations.

## Intended audience

Retail operations, category management, and business analysis stakeholders.

## Success criteria

The project is reproducible from the source CSV, SQL queries are readable and reusable, charts have clear labels, and all findings are traceable to calculated results.
